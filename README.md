# Pretty Prismatic Princess

A glowing, rainbow-splitting mobile browser game in a single HTML file.

## How to play

- **Hold and drag (light mode):** steer the princess into white beams of light to shatter them into glowing pixels.
- **Let go (dark mode):** she stands still and pulls nearby pixels in. Gather enough before time runs out.
- **Prism Vortex:** split two beams back to back and every pixel on screen spirals into her. Watch for Crossfire beams that meet at a star.

There are 100 levels with different themes (Crossfire, Laser Rain, Fading Fast, Bouncy Castle and more), a Rainbow Storm every tenth level, and ten procedural chiptune songs. Music and sound effects can be toggled separately.

Keyboard works too: hold Space for light mode and steer with the arrow keys.

## Run it

Open `index.html` in any modern browser. There is no build step and no dependencies (fonts load from Google Fonts).
